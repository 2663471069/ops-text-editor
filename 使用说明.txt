海报 / 亚马逊副图 文案修改工具
==============================

传一张图 → 自动识别图上的文字 → 改成新文案 → 出图。


怎么跑起来
----------

前提：电脑上装了 Node.js（20 版本以上）。没装就去 https://nodejs.org 下载安装。

1. 把这个文件夹解压到任意位置
2. 在文件夹里打开终端（在地址栏输入 cmd 回车，或右键「在终端中打开」）
3. 依次执行：

       npm install
       npm start

4. 浏览器打开 http://127.0.0.1:8787

第 3 步的 npm install 只需要做一次，之后每次只要 npm start。


第一次使用
------------------

默认使用当前电脑已经登录的 Codex 进行文字识别和生图，不需要在项目里填写密钥。
请保持 Codex 登录状态；上传图片后，Codex 视觉识别通常需要十几秒。

打开 http://127.0.0.1:8787/config.html

【文字识别】选服务商，填对应的密钥：
  - Codex     → 默认，不需要 OCR API Key
  - 阿里云    → AccessKey ID + AccessKey Secret
  - 腾讯云    → SecretId + SecretKey（还要填地域，如 ap-guangzhou）
  - 百度智能云 → API Key + Secret Key
  - 假数据    → 不需要密钥，但识别结果是假的，只能用来试界面

填完点「测试连接」，它会用一张程序生成的测试图跑一次真实识别，
直接告诉你密钥通没通、识别出了什么。

【出图方式】三种：
  - Codex 生图  → 默认；复用当前电脑的 Codex 登录态，不需要项目单独保存 API Key
  - 本地合成    → 不需要密钥，几秒完成；复杂背景可能留痕
  - API 生图    → 需要图像编辑 API Key，适合独立部署或多人使用


三种出图方式怎么选
------------------

Codex 生图：页面点击生成后，后台调用当前电脑已经登录的 Codex 和内置生图能力。
  优点：不需要单独配置图片 API Key，复杂背景也能自然处理
  注意：复杂商品图通常需要 5-15 分钟，会消耗 Codex 使用额度；只适合本机运行

本地合成：在原图上把旧文字按背景色盖掉、重画新文字。
  能用：文字压在纯色底、纯色色块、浅渐变上（信息图、卖点罗列图大多是这种）
  会露馅：文字压在产品实拍照、明显渐变、纹理上；带描边/阴影/渐变的艺术字

API 生图：把原图和提示词交给图像 API 重绘。
  适合服务器或多人部署，但需要密钥、按次收费。

个人本机优先选 Codex；追求速度且背景简单时选本地合成；正式部署选 API 生图。
切换只要在设置页点一下，不用改代码。


自动保存和生成记录
------------------

- 识别完成后会自动建立草稿，修改文案后约 0.7 秒自动保存
- 在文案框输入“消除”“删除”“去除”或“清除”，会清除该识别范围内的文字并补全背景
- 刷新页面会自动恢复上次的原图、识别框和未生成的修改
- 编辑页面会实时显示“本次修改记录”，点击一条记录可以定位到对应识别框
- 顶部点「修改记录」可以查看具体文案变化、修改前后、下载结果、继续编辑或删除记录
- 生成完成页面和每条历史记录都会单独显示本次图片生成耗时
- 点“修改下一张”会清除当前草稿并回到上传页，已经生成的历史记录仍会保留
- 修改前、修改后和记录里的图片都可以点击放大；按 Esc 或点黑色背景关闭
- 替换文字会以原识别框中的文字为样式参照，尽量保留原字体外观、字号、颜色/渐变、粗细、描边、阴影、间距、对齐和位置；新文案太长时只做最小必要缩小。AI 对特殊品牌字体可能只能做到近似，请放大复核重要成图
- 已接入本机 data/fonts/ 下的公司字体；每条文案可在“字体”下拉框选择字体与字重，不选择则自动保留原样。字体文件不会上传到公开 GitHub，给同事部署时请单独复制 data/fonts/ 并确认授权
- 数据只保存在本机 data/workspace/，不会上传到 GitHub
- 记录默认最多保留 50 条、最长 30 天


目录里有什么
------------

server/          后端
  index.js         服务入口和接口
  config.js        配置与密钥存取
  validate.js      输入校验
  position.js      坐标 → 中文位置描述
  prompt.js        提示词拼装
  queue.js         并发控制
  task-store.js    任务存储
  workspace-store.js  草稿和生成记录存储
  ocr/             codex / aliyun / tencent / baidu / mock 五个识别适配器
  image/           codex（Codex 生图）/ local（本地合成）/ openai（API 生图）

.agents/skills/  项目内 Codex 海报文案修改技能

public/          网页界面
test/            测试脚本
README.md        技术说明（给开发者看的）


几个能自己跑的检查
------------------

    npm test                      跑单元测试
    node test/ocr-probe.mjs       用测试图打一次真实 OCR，看密钥和坐标质量
    node test/render-check.mjs    看本地合成在理想条件下的效果，结果在 output/
    node test/e2e.mjs             完整流程走一遍


安全提醒
--------

- 密钥存在 data/config.json，这个文件不进版本库、也不在本压缩包里
- 服务默认只监听 127.0.0.1，同一个局域网里别人也连不进来
- 如果确实要让别人访问，设置环境变量 HOST=0.0.0.0，
  并且务必同时设 ACCESS_TOKEN=你自己定的口令，否则等于裸奔


已知不足
--------

- 不能手动添加/删除/调整文字框。OCR 识别漏了或框偏了，目前没法修正
- 竖排文字的本地渲染比较粗糙（只是把字竖着排，字间距未优化）
- 本地合成还原不了描边、阴影、渐变字，也匹配不了品牌字体
- 重启服务会中断正在生成的任务；草稿和已经完成的记录不会丢失
- Codex 生图依赖当前电脑保持 Codex 登录状态，不适合公网服务器
- 上游请求失败没有重试
