海报文案修改工具——同事安装说明
================================

每位同事在自己的电脑独立运行，使用自己的 Codex 登录状态和使用额度。
草稿、生成记录和上传图片只保存在各自电脑，不会同步给其他人。

一、需要安装
------------

1. Windows 版 Codex 桌面应用，并登录自己的账号。
2. Node.js 20 或更高版本：https://nodejs.org/
3. 从项目 GitHub 页面下载 ZIP 并解压：
   https://github.com/2663471069/ops-text-editor

注意：不要直接在 ZIP 压缩包里面运行，请先完整解压。

二、第一次使用
--------------

1. 打开解压后的 ops-text-editor 文件夹。
2. 双击“首次安装.bat”，等待出现“安装完成”。
3. 双击“一键启动.bat”。
4. 浏览器会自动打开 http://127.0.0.1:8787/
5. 使用期间不要关闭黑色启动窗口。

三、以后使用
------------

以后只需要双击“一键启动.bat”，不必重复安装。
使用结束后，在黑色窗口按 Ctrl+C 停止工具，再关闭窗口。

四、公司字体
------------

GitHub 不包含公司的字体文件。管理员提供字体包后，将字体文件复制到：

    data\fonts\

支持 TTF、OTF、TTC、WOFF 和 WOFF2。复制后重启工具即可看到字体。
使用公司字体前请确认公司拥有相应授权。

五、更新版本
------------

从 GitHub 重新下载最新 ZIP，解压到一个新文件夹，然后运行一次
“首次安装.bat”。旧版本的 data 文件夹保存草稿、历史记录、设置和字体，
需要保留时可将旧版本的 data 文件夹复制到新版本中。

六、常见问题
------------

1. 页面显示“无法访问”：确认“一键启动.bat”的黑色窗口仍然打开。
2. 显示 Codex 不可用：打开 Codex 桌面应用并确认已经登录，然后重启工具。
3. 首次安装失败：确认网络正常、Node.js 版本不低于 20，并将错误截图发给管理员。
4. 生成较慢：复杂商品图通常需要数分钟，会使用当前同事自己的 Codex 额度。
5. 端口被占用：先关闭其他正在运行的本工具窗口，再重新启动。
